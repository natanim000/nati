# Study Motivation — Native Android Final

Standalone Android app. No Expo or React Native dependency.

## Today
- Interactive daily study checklist with persistent completion state.
- Daily progress bar and reset.
- 25-minute focus timer with Start/Pause/Resume/Reset.
- Quick actions for Journey and a new quote.

## Journey
- Live countdown to July 1, 2027.
- Physics MCQ tracker with +5/+10 controls.
- Daily motivation with quote and author.
- Study rhythm and roadmap phases.

## Targets
- Subject target scoreboard for Physics, Chemistry, Biology, Math, English and Aptitude.

## Widget
- Compact home-screen widget only: day number, countdown, daily quote, and quote author.
- Quote changes automatically each day and reschedules after reboot.
